# MailPulse v0.2.0

邮件中心、LLM 翻译与界面体验更新。

## 新功能

- 新增邮件中心：读取最近邮件、查看正文、写邮件和回复，支持标为已读/未读、删除和右键菜单操作。
- 支持 HTML 邮件预览、内嵌图片及链接打开；同一封未读邮件打开正文超过 5 秒后自动标记为已读。
- 微软邮箱新增自有 Entra + Microsoft Graph 接入，统一用于读取、监控、已读状态、删除和发送；保留旧版设备码兼容入口。
- 新增邮件翻译：复用现有 LLM 配置，将主题与文本正文翻译为简体中文，支持原文/译文切换。
- 长邮件按段翻译，每段独立等待至少 120 秒，显示进度和等待时间；取消或失败后可继续，已完成部分无需重新翻译。
- 邮件中心新增验证码提取测试，可验证本地规则、LLM 兜底及提醒弹窗流程。

## 优化与修复

- 规则编辑采用独立弹窗，提供填写示例和规则测试。
- 统一账户编辑、服务器地址与端口、浅色下拉框、按钮等待状态及现代化菜单样式。
- 增加应用、窗口和托盘图标；优化通知的正文节选、按钮布局及 AI 来源图标。
- 修复暂停监控无效、部分邮件中文乱码、邮件列表横向滚动遮挡及配置并发读写冲突。
- 改善微软 OAuth 令牌处理、失败退避、Graph 收件人地址解析和邮件读写体验。

## 下载与升级

- 推荐下载 `MailPulse-v0.2.0-win.zip`，将内容解压到同一目录后运行 `MailPulse.exe`。
- 也可分别下载 `MailPulse.exe` 和 `MailPulse.exe.config`，两者须放在同一目录。
- Windows 10/11，需 .NET Framework 4.8；应用依赖已内嵌，不需要安装 .NET SDK。
- 升级前退出旧版程序。用户配置仍在 `%AppData%\MailPulse`；建议先备份该目录，再替换程序文件。发布包不包含任何个人配置、凭据或日志。
- `SHA256SUMS.txt` 提供下载文件的 SHA-256 校验值。

## 使用说明与已知限制

- 微软邮箱建议使用自有 Entra 公共客户端 + Microsoft Graph，配置 `Mail.ReadWrite` 和 `Mail.Send` 委托权限，详见 README。旧第一方快速登录的新授权可能因预授权策略失败，不能保证可用。
- 翻译使用第一个已启用且配置有效的 LLM，无需开启验证码 LLM 兜底；仅发送主题与文本正文，不发送附件或图片。超过 24,000 字符的邮件暂不支持整封翻译。
- 分段翻译提高长邮件的可恢复性，但耗时仍取决于模型服务。AI 译文仅供参考，原邮件始终保留。
- 当前 MailKit 4.8.0 依赖存在已知的中等级别安全告警（NU1902 / GHSA-9j88-vvj5-vhgr），本版未升级该依赖；后续升级需回归 IMAP、POP3、SMTP 与 OAuth 路径。

## 验证

- Debug / Release 构建及三种 LLM 协议的模拟回归测试。
- 分段完整性、取消、断点继续、原文切换、过期响应保护与验证码分类兼容性测试。
- 使用已配置的 LLM 对虚构长文本进行实际翻译测试，不将测试者的真实邮件加入发布包。
