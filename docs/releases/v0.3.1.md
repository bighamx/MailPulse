# MailPulse v0.3.1

修复 HTML 邮件翻译的完整性、并行回填及失败续传问题。

## 修复

- HTML 段落按实际 ID 更新，乱序完成时不再漏掉译文；页面加载期间未成功更新的节点会重试。
- 保留嵌套块前后的正文和无外层标签的 HTML 片段，避免只翻译最内层段落。
- 首个请求失败或超时后，取消同批在途及排队请求；完成数量根据实际保留的译文统计。
- 属性翻译校验整批结果，HTTP 错误、超时、取消或无效响应不再被标为成功；重试只补译未完成内容。
- 已加载页面支持独立更新图片说明等属性，保留原有链接、图片与排版。

## 下载与升级

- 仅提供 `MailPulse-v0.3.1-win.zip`；请完整解压，将 `MailPulse.exe` 与 `MailPulse.exe.config` 放在同一目录运行。
- 适用于 Windows 10/11，需要 .NET Framework 4.8，不需要安装 .NET SDK。
- 升级前退出旧版。配置仍位于 `%AppData%\MailPulse`，建议先备份；发布包不包含个人配置、Key、令牌、邮件或日志。
- ZIP 包内包含 LICENSE、发布说明及文件 SHA-256 校验值。本版遵循仓库的 Selective Freedom License (SFL) v1.0。

## 验证与已知事项

- Debug / Release 构建通过，两个配置分别通过 180 项回归断言。
- 新增混合 HTML、乱序回填、首错停止、超时取消、属性校验与重试测试，包含真实 WPF 浏览器 DOM 更新验证；测试使用虚构内容和模拟接口。
- 本版未调整依赖版本。NuGet 审计仍报告来自 Costura.Fody 的传递依赖 `System.Net.Http 4.3.0` 和 `System.Text.RegularExpressions 4.3.0` 的 High 告警，当前 Windows/net48 的实际适用性尚未确认；本版不宣称已消除全部依赖安全告警。
- AI 译文仅供参考；翻译不改变服务器上的原邮件。
